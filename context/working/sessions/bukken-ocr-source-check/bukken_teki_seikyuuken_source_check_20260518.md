### 4.2 問題2 / KB2025-p245-q01 seq=2（書籍 #2）

- 書籍 ab記号: × ✓ data ab=false 一致

**Current Q**:
> Aが所有する甲土地の上に、Bが無権原なく乙建物を建設してこれをCに譲渡した場合、無権原で乙建物を建設することによってAの土地所有権を侵害したのはBであるから、AはCに対してのみ乙建物の収去を求めることができる。

**書籍 Q**（image 左 p.592 #2）（image 解像度に基づく読み取り）:
> A所有の甲土地の上に、Bが無権原なく乙建物を建設してこれをCに譲渡した場合、Bが現実に乙建物の所有権を保有することによってAの土地所有権を侵害しているとは認められないので、AはBに対してのみ乙建物の収去を求めることができる。

⚠️ **重要な caveat**: Q 末尾の「**Bに対してのみ**」vs「**Cに対してのみ**」の判別が image 上で完全には確定できない。ただし以下の論理整合性が **Bに対してのみ** を強く示唆:

1. 書籍 E が「AはCを相手方として…Bに対して求めることはできない」と明記 → 法的に正しい target は C
2. もし肢が「Cに対してのみ求めることができる」なら、答えは ○（肢の主張は法的に正しい）
3. しかし書籍 ab=× である
4. ab=× が成立するためには、肢が「Bに対してのみ求めることができる」（誤った主張）でなければならない
5. → 書籍 Q は **「AはBに対してのみ」** で確定的

**Current E**:
> 判例（最判昭35.6.17）は、土地の所有権に基づく建物収去土地明渡請求をする場合、現実に家屋を所有することによって現実にその土地を占拠して土地の所有権を侵害している者を相手としなければならないとしている。したがって、AはCを相手方として建物収去土地明渡請求をしなければならず、Bに対しては求めていない。

**書籍 E**（image 右 p.593 #2）:
> × 判例（最判昭35.6.17）は、土地の所有権に基づく建物収去土地明渡請求をする場合、現実に家屋を所有することによって現実にその土地を占拠して土地所有権を侵害している者を相手としなければならないとしている。したがって、AはCを相手方として建物収去土地明渡請求をしなければならず、Bに対して求めることはできない。

差分:
- 「土地の所有権」/「土地所有権」（軽微）
- 「Bに対しては求めていない」→ 「Bに対して求めることはできない」（**末尾の意味変化**）

→ E 末尾は **exact source-confirmed**。

**Q 中央部の追加差分**:
- data: 「無権原で乙建物を建設することによってAの土地所有権を侵害したのはBであるから」
- 書籍（推定）: 「Bが現実に乙建物の所有権を保有することによってAの土地所有権を侵害しているとは認められないので」

意味反転を含む大幅な構造差分。image 上で書籍テキストは読めるが中央部の正確な助詞・句読点は確認の余地あり。

**分類**:
- **Q**: 「Bに対してのみ」vs「Cに対してのみ」: **inferred-strong**（answer logic + ab consistency による論理的確定だが、image character 自体は完全 exact-confirmed ではない）→ user 物理確認推奨
- **Q 中央部**: **caveated**（image 読み取りに微小不確実性）
- **E 末尾**: **exact source-confirmed**（「求めていない」→「求めることはできない」）
- **answerBoolean**: false で **正しい**（書籍 × と一致）

**answerBoolean 疑い**: なし（書籍 × と data false 一致）。ただし **Q が現状の「Cに対してのみ」のままだと、肢の主張と ab の論理矛盾が data に残る**。Q patch が必須となる構造。

### 4.3 問題3 / KB2025-p245-q01 seq=3（書籍 #3）

- 書籍 ab記号: ○ ✓ data ab=true 一致

**Current Q**:
> Aが所有する甲土地の上に、Bが無権原なく乙建物を建設し、自己所有名義で建物保存登記を行った。そしてそれをCに譲渡したが、建物所有権登記がB名義のままとなっていた場合、Aは登記名義人であるBに対して乙建物の収去を求めることができる。

**書籍 Q**（image 左 p.592 #3）:
> A所有の甲土地の上に、Bが無権原なく乙建物を建設し、自己名義で建物保存登記をした。その後、Bは乙建物をCに譲渡したが、建物所有権登記がB名義のままとなっていた場合、Aは登記名義人であるBに対して乙建物の収去を求めることができる。

差分:
- 「Aが所有する」→「A所有の」（軽微）
- 「自己所有名義」→「自己名義」（軽微）
- 「建物保存登記を行った。そしてそれをCに譲渡した」→「建物保存登記をした。その後、Bは乙建物をCに譲渡した」（中程度、構造差分）

→ data Q と書籍 Q の差分は意味を変えない軽微〜中程度の wording 差分。

**Current E**:
> 判例（最判昭56.2.8）は、177条未登記を遡及しないことから、他人の土地上の建物の所有権を取得した者からの意思に基づいて所有権取得の義務を負担した場合に、たとえ登記を他に譲渡したとしても、登記名義を保存する限り、土地所有者がこれ対して、譲渡による建物所有者の喪失を承認して建物収去・土地明渡しの義務を免れることはできないとしている。

**書籍 E**（image 右 p.593 #3、判読困難領域あり）:
> ○ 判例（**最判平6.2.8**）は、177条の登記なくして第三者に対抗できないなどの規定により、他人の土地上の建物の所有権を取得した者は、自己の意思に基づいて所有権を取得した以上、その後たとえ建物を他に譲渡したとしても、登記名義を保有する限り、土地所有者に対して、譲渡による所有権の喪失を主張して建物収去・土地明渡しの義務を免れることはできないとしている。

⚠️ **caveat**: 書籍 E の中央部は image 解像度で部分的に読みにくい。判例日付と全体構造は exact-confirmed だが、個別の助詞・接続詞レベルでは推定読みが含まれる。

差分（exact-confirmed 部分）:
- **「最判昭56.2.8」→「最判平6.2.8」**（user 指摘どおり、判例日付完全変更）
- 「177条未登記を遡及しないことから」→「177条の登記なくして第三者に対抗できないなどの規定により」（中央部構造崩壊）
- 「取得した者からの意思に基づいて所有権取得の義務を負担した場合に」→「取得した者は、自己の意思に基づいて所有権を取得した以上、その後」（主体・条件構造崩壊）
- 「登記名義を保存する限り」→「登記名義を保有する限り」（「保存」→「保有」、軽微）
- 「土地所有者がこれ対して」→「土地所有者に対して」（助詞「が」削除）
- 「譲渡による建物所有者の喪失を承認して」→「譲渡による所有権の喪失を主張して」（意味反転：「承認」→「主張」、「建物所有者」→「所有権」）

**分類**:
- **Q**: **軽微 P3 patch 候補**（書籍 wording に揃える）
- **E 判例日付**: **exact source-confirmed**（「最判昭56.2.8」→「最判平6.2.8」）
- **E 全文**: **caveated**（中央部の image 読み取りに不確実性）。判例日付以外の全文置換は推定要素を含むため、image 再撮影 / 物理書籍確認後に exact transcription を確定したい
- **answerBoolean**: true で正しい

**answerBoolean 疑い**: なし。
