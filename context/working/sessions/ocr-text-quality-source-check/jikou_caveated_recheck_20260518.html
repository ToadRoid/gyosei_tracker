11. blocked / caveated 理由

  • 両 Q とも、書籍中央部の文字が image の resolution / typeset / OCR 由来の判読困難領域に位置している
  • raw image（3.1MB）でも outer structure は読めるが、具体的助詞・主語確定に必要な精度に届かない
  • 推定で patch すると、書籍と異なる文言を data に焼き付ける副作用がある
