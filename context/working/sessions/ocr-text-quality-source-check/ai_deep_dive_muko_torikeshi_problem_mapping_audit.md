## 重要な観察

### P0 #2 が前回 audit と質的に異なる

前回の `03_代理` audit の P0 #15 は **answerBoolean 逆転疑い**。今回の P0 #2 は **answerBoolean は正しいが explanationText が法的に誤っている**。

学習被害の構造:
- 問題自体は false で正しく分類されている
- ユーザーは「相手方は現存利益返還で足りる」と書いて誤りと分かる
- しかし解説が「相手方は…善意であれば現存利益の返還義務を負う」と書いていて、これは民法上誤り（121条の2第3項は制限行為能力者保護の特則）
- → ユーザーは誤った法的知識を覚える

**この種の「結論は合っているが解説が誤り」は最も危険**。テストでは外見上問題なく見えるが、知識ベースとしては腐敗する。

### P0 #8 は #15 / #30 と同類だが正答影響は小

Q OCR 崩れで読解不能だが、論点（強迫の畏怖継続による126条起算点遅延）が解説から推定でき、ab=true は論理整合する。
ただし source 確認なしに Q を「畏怖継続」と直書きするのは推測。**原本確認必須**。

8 問のうち 6 問が p.236（KB2025-p236-q01）に集中。前回の `03_代理` audit でも p.231 / p.233 に崩れが集中していた → **特定ページの parser/OCR 品質に系統的問題**がある可能性。
