7. data patch 対象

本 PR では data patch を行わない。

理由:

  1. 86% の branches が image 不在で exact 確認不能
  2. 「inferred」だけで正規化を強行すると、参考書と異なる分類体系を data に焼き付けるリスク
  3. 親見出しの「物権総論」「担保物権」を分解するには、各 problemId がどの sub-section に属するか書籍で確認しなければならない（127 件の確認作業）
